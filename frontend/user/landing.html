Features

Everything a product team needs, nothing it doesn't

No setup maze, no plugin store. The parts you use every day, made fast.

  • ☰

    Issues, list and board

    Status, assignee, priority, labels and due dates. Filter, group and drag issues into the order you want; everyone sees it live.

  • ↻

    Cycles

    Plan the next sprint, watch progress as it happens and roll unfinished work into the next cycle in one click.

  • ✎

    Live descriptions

    Write specs together in rich text. Cursors, mentions and comments update for everyone in real time.

  • ⌘

    Keyboard first

    A command palette, quick create and instant search. Get from idea to issue without touching the mouse.

  • ◎

    Chat beside the work

    Channels and direct messages that link straight to issues, so decisions stay next to the work they're about.

  • ▤

    Team analytics

    Workload, completed issues per week and cycle time for each member. Clear numbers, no leaderboards.

Workflow

Your process, not ours

Shape Tether around how your team already works.

Custom statuses and labels

Add the steps your work really goes through, from triage to released, and colour-code labels for every area of the product.

  • Backlog, todo, in progress, done and cancelled categories
  • Per-workspace labels with colours
  • Watch any issue to follow its changes

Roles with real permissions

Start with Admin and Member, then build your own roles. Decide exactly who can create projects, edit any issue, run tests or see analytics.

  • Private projects for sensitive work
  • Invite by email, with a role from the start
  • Control who can create new workspaces

Customer feedback, linked to issues

Share a public feedback form, collect requests from customers and turn the good ones into issues without copy and paste.

  • Public form with your own link
  • Link feedback to the issue that fixes it
  • Email and in-app notifications

AI testing

Write test cases in plain words. Let AI click through them.

Add test cases to an issue and Tether runs them in a real browser, step by step, with screenshots of every step. Save a run as a script and replay it on every release.

  • Watch runs live as they happen
  • Test accounts and sites managed per workspace
  • Mark manual results alongside AI runs

Integrations

Fits the tools you already use

  • GitHub and GitLab

    Link pull requests to issues. Branch names and commit messages are one click away.

  • Claude and MCP

    Connect Claude to your workspace in one command. It can read, create and update issues as you.

  • Webhooks and API

    Send events anywhere and script your workflow with personal API tokens.

claude mcp add --transport http tether https://your-tether.app/mcp
